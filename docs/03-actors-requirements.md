# 5. Действующие лица ИС

Действующими лицами ИС являются:
- Посетитель;
- Пользователь.

**Посетитель** – незарегистрированный пользователь, который имеет доступ только к главной странице приложения и форме регистрации.

**Пользователь** – лицо, которое проходит авторизацию в системе, управляет собственным профилем, редактирует личные антропометрические данные и цели, создаёт, просматривает и редактирует дневные записи, загружает фотографии приёмов пищи, вносит ручные корректировки в значения КБЖУ, массу блюда и состав нутриентов, а также просматривает рассчитанную статистику, рекомендации от ИИ-агента и предложенные рецепты. Кроме того, пользователь взаимодействует с программным эмулятором настольного модуля (умным автоматом перекусов): инициирует запрос на перекус (нажатие виртуальной кнопки) и получает визуальный результат (открытие/закрытие виртуальной заслонки и зеленый/красный индикатор), сформированный на основе проверки текущего дневного лимита калорий.

# 6. Функциональные требования

**Посетителю доступны следующие возможности:**
- зарегистрироваться по электронной почте;
- зарегистрироваться через внешний сервис.

**Пользователю доступны следующие возможности:**
- авторизоваться по электронной почте;
- авторизоваться через внешний сервис;
- заполнить антропометрические данные;
- редактировать антропометрические данные;
- выбрать вектор цели;
- редактировать вектор цели;
- вносить дневную запись;
- редактировать дневную запись;
- получить рекомендации по питанию и физической активности на основе анализа ИИ-агентом;
- запросить перекус.
