
# NutriAI Tracker

**NutriAI Tracker** - это умный помощник для тех, кто хочет легко следить за своим питанием и здоровьем без рутинного и долговременного подсчета калорий.

Вместо того чтобы вручную искать каждый ингредиент в базе данных и взвешивать еду, достаточно просто сделать фотографию своей тарелки. Искусственный интеллект автоматически определит состав блюда, оценит размер порции, рассчитает КБЖУ (калории, белки, жиры, углеводы) и сформирует персональные рекомендации.

---

### Как работает система

 **Мобильное приложение (Android / Java)**
Пользователь регистрируется, заносит свои параметры (рост, вес, возраст) и выбирает цель: похудеть, набрать массу, поддержать форму или улучшить здоровье. В течение дня через приложение загружаются фото приемов пищи, количество шагов, пульс и самочувствие. Если ИИ где-то ошибся с весом порции, любые цифры можно быстро подкорректировать вручную.

**Сервер и ИИ (Linux / FastAPI / Python)**
Принимает фотографии, передает их нейросети для анализа, рассчитывает калорийность, сравнивает показатели с дневной нормой и подбирает полезные советы вместе с подходящими рецептами.

**Настольный модуль (Raspberry Pi / Linux / Python)**
Компактный модуль с эмуляцией OLED-экрана и кнопок. Он мгновенно связывается с сервером по сети и показывает актуальную суточную сводку (сколько калорий съедено, сколько шагов пройдено) в реальном времени.

---

### Что будет готов

Полноценно работающий комплекс из трех компонентов (мобильное приложение + Linux-сервер + виртуальный дисплей Raspberry Pi). Система с точностью от 85% распознает блюда по фотографиям, мгновенно выводит статистику на экран и сохраняет всю историю за прошедшие дни.
